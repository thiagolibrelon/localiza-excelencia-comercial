A árvore de decisão dos problemas

Em boa parte dos casos, o código de problema que a IA atribuiu à ligação não é a causa raiz — é o sintoma de outra coisa, muitas vezes de uma área completamente diferente.

1.844 ligações auditadas 4 categorias (P1 Acesso · P2 Faturamento · P10 Reserva · P12 NPS) leitura integral por 4 agentes especializados 04/08/2026
~38%dos casos são sintoma de outra causa, não a raiz que o código sugere
27%do "problema de boleto" (P2) é, na real, cobrança travando reserva/crédito — não o contrário
99,4%dos casos de manipulação de NPS nunca foram escalados — ninguém no processo vê isso hoje
~11%de "Reserva/sistema" (P10) é falso positivo — não tem nada a ver com reserva

Agrupado pelo que realmente precisa ser consertado

Mesma base de 1.844 ligações, reagrupada pela causa raiz identificada na auditoria — não pelo código que a IA atribuiu de primeira. É a visão acionável: mostra onde investir resolve vários códigos ao mesmo tempo.

Agrupado pelo código original da classificação

A visão como os dados chegaram — cada ligação já rotulada P1/P2/P10/P12 pela IA. Abra cada grupo para ver a mistura de causas raiz escondida dentro do rótulo.

Metodologia

  • Base: ligações de julho/2026 já classificadas por LLM (Gemini) no Prompt 3 (Problemas Recorrentes). Universo tageado: P1=860, P2=572, P10=242, P12=170.
  • Para P1, P2 e P10 (bases grandes), cada agente leu integralmente uma amostra estratificada (ex: AMOSTRA_P1.txt, 242 casos cobrindo todas as sub-categorias já identificadas + 100% dos clientes recorrentes) e varreu por palavra-chave o restante para não perder casos com sinal causal forte. Percentuais são extrapolados da subamostra lida em profundidade, não uma recontagem censitária dos totais.
  • Para P12 (base menor), cobertura foi de 100% — as 170 transcrições foram lidas na íntegra.
  • "Sintoma" = o código original está tecnicamente presente na ligação, mas a causa que precisa ser corrigida está em outra área. "Ruído" = a IA classificou errado; a ligação não trata do tema do código.
  • Citações foram limpas de ruído de encoding pré-existente na fonte (problema de dupla-codificação de acentos) preservando o conteúdo real dito.
